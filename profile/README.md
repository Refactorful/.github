# Refactorful

Refactorful is the home for serious software projects focused on developer tooling, reliability, and maintainable systems. The organization brings together both open-source and closed-source work under a single umbrella, with an emphasis on products that help teams move faster without sacrificing safety or clarity.

Our mission is to build practical software that reduces operational friction, supports thoughtful engineering workflows, and makes complex technical work easier to reason about. We focus on tools, infrastructure, and product experiences that are designed to be dependable in real-world development environments.

## What we focus on

- Developer tools that improve safety, automation, and day-to-day workflow quality
- Database and infrastructure tooling with clear, reviewable change management
- Products that value local-first workflows, explicit control, and predictable behavior
- Long-term software design that prioritizes clarity, maintainability, and strong engineering fundamentals

## Highlights

### migrata-cli

The core Migrata command-line experience for managing database schema changes with safety and clarity.

- **Links:** [Website](https://migrata.io) · [Documentation](https://docs.migrata.io)
- **Use cases:** Version-controlling schemas, previewing migration diffs, and applying changes with explicit review
- **Key features:** Local-first workflow, plain SQL migrations, schema inspection, intelligent diffing, and safe execution

### migrata-cli-releases

Public release and installation repository for Migrata CLI binaries and install scripts.

- **Repository:** [Refactorful/migrata-cli-releases](https://github.com/Refactorful/migrata-cli-releases)
- **Use cases:** Installing Migrata, downloading public releases, and integrating release distribution into team workflows
- **Key features:** Hosted release assets, installation scripts, and a public entry point for trying Migrata
